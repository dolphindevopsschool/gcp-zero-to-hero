# GCP Zero to Hero 2026 (FREE) 🚀

Welcome to **GCP Zero to Hero 2026 (FREE)** — a hands-on, day-by-day journey through Google Cloud Platform. This isn't a theory course. Every video tackles one real GCP task, shows you exactly how to do it, and leaves you with something working (or cleaned up) at the end.

Whether you're starting from zero or brushing up specific skills, this repo holds the code, configs, and notes for every video in the series — building up, over time, into a complete GCP skillset: account setup, IAM, networking, compute, data pipelines, CI/CD, and more.

## 📖 How This Repo Works

Each day gets its own folder with:
- The problem being solved
- The concept behind it
- Step-by-step instructions
- How to verify it worked
- How to clean up afterward (so you don't get billed for it)
